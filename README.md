# ModelMix starter

This is an early website starter for ModelMix.

## Run locally
1. Install Node.js 18 or newer.
2. In this folder, run `npm start`.
3. Open `http://localhost:3000`.

## Deploy on Render
Create a **Web Service** from this GitHub repository.
- Build command: leave blank
- Start command: `npm start`

This starter is only a visual website. It does not yet connect to OpenAI, Anthropic, Google, xAI, user accounts, billing, or the AI Debate Room. Add those securely in later development steps. Never put API keys in browser files or commit them to GitHub.
